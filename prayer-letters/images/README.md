# 사진 폴더

`posts.json`에서 각 글의 `thumbnail`, `images` 값에 적어둔 파일명과 이 폴더의 실제 사진 파일명이 일치해야 사진이 표시됩니다.

## 사진 추가 방법

1. 사진 파일을 이 폴더(`prayer-letters/images/`)에 복사합니다.
2. `../posts.json`에서 해당 글의 `thumbnail`/`images` 값을 실제 파일명으로 맞춰줍니다.
3. 파일명이 맞지 않거나 사진이 아직 없으면, 사이트에는 "사진 준비중" placeholder가 자동으로 표시됩니다 (오류 없이 정상 동작).

## 참고

- Google Drive/외장 드라이브(G:\ 등) 경로는 이 저장소에서 직접 접근할 수 없으므로, 사진은 이 폴더 안에 실제 파일로 있어야 합니다.
- 공개 저장소에 올리는 사진이라면, 상호명·전화번호·주소·차량 번호판 등 특정 위치나 신원이 드러나는 정보가 사진에 찍혀 있지 않은지 한 번 더 확인해 주세요.
